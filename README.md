### ALGO-000002: NP versus coNP
- **Subfield:** core complexity
- **Open:** Is NP = coNP? Equivalently, do complements of NP problems have short certificates?
- **Status:** Open since the 1970s; believed false. Implies P ≠ NP if separated. No oracle with insight; duality phenomena (LP, semidefinite) show partial worlds where it holds.
- **Type:** theory
- **Why:** Separation would rule out short proofs of unsatisfiability (SAT refutations), bounding proof systems and many verification tasks.
- **Key works:** S. Cook, "The complexity of theorem-proving procedures", STOC 1971; S. Arora, B. Barak, "Computational Complexity: A Modern Approach", Cambridge 2009, ch. 3-5
- **Aliases:** coNP vs NP
